# Hypothesis Editor

> Every Great Solution Starts with a Hypothesis.

A lightweight, extensible, and modern code editor designed for a fast, customizable, and productive development experience — with built-in AI, browser, database, REST client, live server, tunnels, and more.

## ✨ Features

### 🖊️ Editor
- Syntax highlighting for 50+ languages
- Multi-tab editing, auto-save, format on save
- 4 built-in themes, font picker
- Diff viewer, split preview panel
- File preview: HTML, Markdown, SVG, images, audio, video

### 🤖 AI Agent
- Autonomous AI with file read/write, terminal, and git tools
- Multiple AI providers, streaming chat, session persistence
- AI inline edit (`Ctrl+K`), right-click → Ask / Fix with AI
- Open with `Ctrl+Shift+A`

### 💬 Chat Collaboration
- Real-time chat rooms over LAN or public URL via Tunnel
- Host, join, kick participants
- Opens as a dedicated editor tab

### 🌐 Web Browser
- Embedded browser with tabs, bookmarks, history, downloads
- Find in page, zoom, DevTools
- Open with `Ctrl+Shift+B`

### 🌍 Live Server
- Serve any local folder as a live website with auto-reload
- SPA mode, HTTPS, CORS, per-request log
- Open via Panel → Live Server

### 🔌 Tunnels
- Forward any local port to a public URL instantly
- Multiple tunnels, auto-reconnect, request log
- Open via Panel → Tunnels

### 🗄️ Database Explorer
- Connect to SQLite, PostgreSQL, MySQL/MariaDB
- Schema browser: tables, views, columns, indexes, foreign keys
- Table data viewer with pagination, inline cell editing, FK navigation
- Export table data as CSV, JSON, or SQL
- Multi-tab query editor, query history
- ER Diagram with pan, zoom, draggable cards, minimap, PNG/SVG export
- Open with `Ctrl+Shift+D`

### 🔧 REST Client
- Collections, environments, auth (Bearer, Basic, OAuth2, API Key, AWS SigV4)
- Pre-request & test scripts, response viewer, collection runner
- Import from Postman, OpenAPI, Insomnia, cURL, HAR
- Open with `Ctrl+Shift+R`

### 📊 Project Insights
- Language breakdown, complexity, dependencies, security scan, git health
- Health score with recommendations

### 🔀 Git
- Stage, commit, push, pull, fetch, branch, merge, stash, diff, log
- AI-generated commit messages

### 💻 Terminal
- Integrated terminal with multiple instances
- Run output captured to Console/Problems panels

### 📁 File Explorer
- Multi-root workspace, create/rename/delete/move, drag-and-drop

### 🔍 Search & Replace
- Full-text search across workspace with live replace preview

### 🔌 Extensions
- Install `.hyp` extensions, enable/disable from sidebar

### ⌨️ Command Palette
- `Ctrl+Shift+P` — access all commands instantly

## 🔌 Extensions

Hypothesis supports a lightweight extension system. Extensions are `.hyp` files installable from the Extensions sidebar.

Browse community extensions at the [**Hypothesis Extension**](https://github.com/Hypothesis-Studio/Hypothesis-Extension) repository.

Build your own using the [Extension Boilerplate](https://github.com/Hypothesis-Studio/Hypothesis-Extension/tree/main/Extention-Boilerplate).
